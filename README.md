## 📖 Overview

Writing a good blog post usually means three separate jobs: researching the topic, writing a draft worth reading, and finding or making an image for it. **Inkwell** is a LangGraph agent that does all three in one run — it researches the topic with Tavily, drafts and refines the post with an OpenAI model, generates a cover image with Gemini, and hands you a ready-to-publish Markdown file from a Streamlit UI.

The `1_bwa_basic.ipynb` → `5_bwa_image.ipynb` notebooks in this repo show the project's build order: a basic generation chain, then improved prompting, then web research, then a fine-tuned research step, then image generation — before it was packaged into the Streamlit app.

## ✨ Features

- 🔎 **Web research** — pulls current information on the topic via Tavily before writing, instead of relying on the model's training data alone
- ✍️ **AI drafting & refinement** — generates a structured blog post and iterates on prompting for quality
- 🎨 **AI cover image** — generates a matching header image with Google's Gemini (`google-genai`)
- 💾 **Local storage** — saves generated posts and session data to a local SQLite database (`bwa.db`)
- 🚀 **One-click publish** — `bwa_publish.py` handles exporting/publishing the finished post
- 🎭 **Themed Streamlit UI** — custom dark theme (`bwa_theme.py`) for the writing dashboard

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- An OpenAI API key
- A Google Gemini (`google-genai`) API key
- A [Tavily](https://tavily.com/) API key

### Installation

```bash
git clone https://github.com/Ariesjeev/blog-writing-agent.git
cd blog-writing-agent

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### Configuration

Create a `.env` file in the project root:

```env
OPENAI_API_KEY=your_openai_api_key
GOOGLE_API_KEY=your_gemini_api_key
TAVILY_API_KEY=your_tavily_api_key
```

### Run

```bash
streamlit run app.py
```

Open `http://localhost:8501`, enter a topic, and let the agent research, write and illustrate the post.

## 🖥️ Usage

1. Enter a blog topic in the Streamlit UI.
2. The agent researches it via Tavily and drafts a post with LangGraph.
3. Review and refine the generated draft.
4. Generate a cover image for the post.
5. Save it (stored in `bwa.db`) and publish it with the built-in publish action.
